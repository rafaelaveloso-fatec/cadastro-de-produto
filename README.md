# Cadastro de Produto

Este repositório contém o código-fonte da aplicação de gerenciamento de produtos.

## Arquivos

* **`root/produto.php`**: Contém a estrutura principal do sistema, integrando o código HTML para a interface de usuário e a lógica PHP para processamento dos dados.
* **`root/produto.css`**: Arquivo de estilos responsável pela estilização e layout visual das páginas.
* **`root/conexao.php`**: Script responsável por estabelecer a conexão do PHP com o banco de dados MySQL local.

## Banco de Dados

O banco de dados da aplicação chama-se **`estoque`**.

Para o funcionamento local (utilizando a estrutura do USBWebServer), os arquivos do banco de dados estão localizados em **`mysql\data\estoque`**
